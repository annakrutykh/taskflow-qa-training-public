# Автотесты — справочно

Это **не часть курса** (см. `CLAUDE.md`, раздел 5) — вам не нужно писать
или запускать автотесты самостоятельно. Этот файл нужен на случай, если
куратор или автотестер попросит вас прогнать тесты — он даст вам конкретную
команду, а здесь можно быстро посмотреть, что она делает.

В проекте есть три уровня прогона (`pytest` под капотом, обёрнуто в `make`):

```bash
make smoke         # быстрый набор — основные сценарии, ~5-10с
make integration   # более полный набор, ~40с
make regression    # всё, включая e2e — самый полный прогон, ~40с
make test-down     # остановить тестовые db/redis, когда закончили
```

Если попросили прогнать конкретную команду — просто выполните её из корня
репозитория (нужен Docker, как и для самого проекта) и пришлите куратору
вывод в терминале.
